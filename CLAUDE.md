# Проект: Библиотека мини-помощников

## Что это

Личная растущая библиотека мета-промптов (мини-помощников) для разных задач — жизни, работы, творчества, разработки.

## Как работать с проектом

**Первым делом читай:** [`assistants-library/INDEX.md`](assistants-library/INDEX.md) — там карта всей библиотеки и быстрый поиск по тегам.

**Шаблон и правила добавления помощника:** [`assistants-library/01-rules.md`](assistants-library/01-rules.md)

**Цель проекта:** [`assistants-library/00-brief.md`](assistants-library/00-brief.md)

## Структура

```
assistants-library/
├── INDEX.md              ← карта библиотеки, читать первым
├── 00-brief.md           ← цель и критерии качества
├── 01-rules.md           ← шаблон помощника + правила добавления
├── 04-decisions-log.md   ← лог структурных решений
└── assistants/
    ├── analysis.md       ← Анализ и критика
    ├── ideas.md          ← Генерация идей
    ├── writing.md        ← Работа с текстом
    ├── planning.md       ← Планирование
    ├── code.md           ← Разработка
    ├── content.md        ← Контент и творчество
    └── decisions.md      ← Принятие решений
```

## Команды

- **"Создадим помощника"** → читаю INDEX.md, уточняю категорию и теги, заполняю шаблон из 01-rules.md
- **"Найди помощника для X"** → читаю INDEX.md, ищу по тегам или категории, возвращаю готовый промпт
- **"Добавь категорию"** → создаю новый файл в assistants/, обновляю INDEX.md, пишу в decisions-log

## Правила для Claude

1. При любой работе с библиотекой — начинай с INDEX.md
2. После добавления помощника — обновить счётчик и таблицу тегов в INDEX.md
3. decisions-log обновлять только при структурных изменениях (новая категория, изменение шаблона) — не при каждом добавлении помощника
4. Не добавлять Co-Authored-By в коммиты

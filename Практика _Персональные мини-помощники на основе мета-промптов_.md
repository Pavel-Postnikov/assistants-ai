# Практика

Модуль 3. Индивидуальный контур

## Персональные мини-помощники на основе мета-промптов

### Суть проекта

Ты создаёшь **несколько мини-помощников**, каждый из которых работает **по своему мета-промпту** и предназначен **для конкретной цели в твоей жизни или работе**.

Это не «разные вопросы одному ИИ». Это **разные роли, правила и поведение**.

## Цель проекта

- научиться управлять поведением LLM через мета-промпты
- перестать использовать ИИ одинаково для разных задач
- собрать **персональный набор помощников**, которые реально тебе полезны

## Что нужно сделать

1.  Выбрать **3 разные сферы**, которые реально присутствуют в твоей жизни
2.  Для каждой сферы создать **одного мини-помощника**
3.  Для каждого помощника написать **полноценный мета-промпт**
4.  Объяснить, **как и зачем ты будешь его использовать**

## Шаг 1. Выбор направлений (обязательно свои)

Выбери **3 направления**, которые реально для тебя важны.

Примеры направлений (можно свои):

- работа / проекты
- хобби / творчество
- спорт / здоровье
- еда / быт
- финансы
- личная организация
- коммуникация

**Важно:**

- Учебные темы использовать нельзя
- Направления должны быть **разные по цели**, а не «всё про работу»

## Шаг 2. Формат одного мини-помощника

Для **каждого помощника** ты оформляешь один блок.

### 1. Назначение помощника

Коротко и конкретно:

- какую проблему решает
- в каких ситуациях ты его вызываешь

Пример формулировки:

    Этот помощник нужен мне, когда …
    Я использую его в ситуациях …

### 2. Поведение помощника (мета-промпт)

Это **главная часть задания**.

Мета-промпт должен описывать:

- роль
- цель
- ограничения
- стиль мышления
- формат ответа
- чего помощник делать не должен

**Важно:**

- Это не один абзац
- Это инструкция поведения

**Структура мета-промпта (обязательно):**

    Роль:
    Цель:
    Принципы работы:
    Ограничения:
    Формат ответа:
    Запрещено:

### 3. Пример реального использования

Опиши **один конкретный сценарий**, где этот помощник тебе помогает.

Не абстрактно, а по жизни:

    Я использую этого помощника, когда …
    Ожидаемый результат для меня — …

### 4. Польза лично для тебя

Ответь **своими словами**:

- какую нагрузку снимает
- какую ошибку предотвращает
- почему обычный ИИ без мета-промпта тут хуже

## Примеры направлений и целей

Для идей, не для копирования:

### Работа

- помощник для критики решений
- помощник для превращения задач в действия
- помощник для проверки рисков

### Хобби

- помощник для генерации вариантов
- помощник для выхода из творческого тупика

### Быт / еда

- помощник для упрощения решений
- помощник для ограничения вариантов

### Спорт / здоровье

- помощник для проверки реалистичности планов
- помощник для контроля нагрузки

### Финансы

- помощник для проверки импульсивных решений
- помощник для анализа последствий

**Важно:** Это **идеи направлений**, а не готовые помощники.

## Пример качественного мета-промпта

### Помощник: Критик технических решений

**Назначение:** Этот помощник нужен мне, когда я выбираю технологию или архитектурное решение для проекта и хочу увидеть потенциальные проблемы до того, как начну реализацию.

**Мета-промпт:**

    Роль:
    Ты критик технических решений. Твоя задача — находить слабые места в предлагаемых решениях, а не поддерживать идеи.

    Цель:
    Помочь мне увидеть риски, которые я могу упустить из-за энтузиазма или привычки.

    Принципы работы:
    - Задавай неудобные вопросы: "А что если...", "Как это масштабируется...", "Что произойдёт при отказе..."
    - Фокусируйся на 3-5 самых критичных рисках, а не на всём подряд
    - Приводи конкретные примеры из реальной практики, где похожие решения создавали проблемы
    - Предлагай альтернативы только после того, как разобрал риски

    Ограничения:
    - Не давай общих советов ("нужно тестировать", "делай бэкапы")
    - Не предлагай решения, которые я не смогу реализовать в текущих условиях
    - Не уходи в теорию — только практические последствия

    Формат ответа:
    1. Краткое резюме предложенного решения (1-2 предложения)
    2. 3-5 конкретных рисков с примерами
    3. Один вопрос, который поможет мне проверить решение

    Запрещено:
    - Хвалить идею или говорить "в целом хорошо"
    - Давать оценки типа "это плохая идея" без объяснения почему
    - Предлагать переделать всё с нуля

**Пример использования:** Я использую этого помощника, когда выбираю между разными библиотеками или подходами в коде. Ожидаемый результат — список конкретных вопросов, на которые мне нужно ответить перед началом работы.

**Польза:** Снимает когнитивную нагрузку с поиска проблем в собственных идеях. Предотвращает типичную ошибку — влюбляться в решение и игнорировать красные флаги. Обычный ИИ без мета-промпта склонен соглашаться и поддерживать любую идею, что бесполезно для критического анализа.

## Что сдаётся

Создай **один файл** в любом текстовом формате. Подойдёт:

- Google Docs
- Markdown
- Word (.docx)
- PDF
- Obsidian
- Обычный текстовый файл (.txt)

**Важно:** Подойдёт любой текстовый формат, главное — чтобы было удобно читать структуру.

### Структура файла (обязательно):

1.  **Мини-помощник №1**
    - Назначение помощника
    - Поведение помощника (полный мета-промпт по структуре)
    - Пример реального использования
    - Польза лично для тебя
2.  **Мини-помощник №2** (та же структура)
3.  **Мини-помощник №3** (та же структура)

## Задание и статус сдачи

- **Статус:** ответ не найден в сохраненной странице.
- **Форма сдачи:** доступна.
- **Автор формы:** Павел.
- **Доступные действия:** отправить ответ, сохранить черновик, добавить файлы.
- **Ограничение загрузки:** максимальный размер файла — 100 МБ.

# Библиотека мини-помощников

Личная коллекция мета-промптов для разных задач — работы, быта, творчества, разработки.

**Идея простая:** не объяснять ИИ каждый раз одно и то же, а держать готовые инструкции под рукой и просто вызывать нужного помощника.

---

## Что внутри

| Категория | Что там |
|---|---|
| Анализ и критика | Разбор идей, проверка гипотез |
| Генерация идей | Брейншторм, выход из тупика |
| Работа с текстом | Письма, тексты, редактура |
| Планирование | Задачи, планы, структура |
| Разработка | Код, архитектура, ревью |
| Контент и творчество | Посты, сценарии, идеи |
| Принятие решений | Выбор между вариантами |

Полная карта с тегами и быстрым поиском → [`assistants-library/INDEX.md`](assistants-library/INDEX.md)

---

## Как пользоваться

1. Открываешь нужного помощника
2. Копируешь промпт из блока **"Промпт для копирования"**
3. Вставляешь в ChatGPT, Claude или любой другой чат
4. Работаешь

## Платформы

Помощники работают в любом чат-интерфейсе: **ChatGPT, Claude, Яндекс GPT**.  
Часть помощников заточена под ИИ-агенты в IDE: **Claude Code, Cursor, Codex**.

# 00-brief — Цель проекта

## Что это

Личная растущая библиотека мета-промптов (мини-помощников) для разных задач жизни и работы.

## Зачем

Собрать под рукой готовые инструкции поведения для LLM — чтобы не объяснять каждый раз одно и то же, а вызывать нужного помощника с нужными правилами.

## Принципы

- Библиотека живая — пополняется постепенно
- Один помощник = одна конкретная задача
- Помощник может подходить сразу к нескольким сферам — для этого есть теги
- Каждый помощник тестируется в реальном использовании

## Платформы использования

- Чат-интерфейсы: ChatGPT, Claude
- Разработка: Claude Code, Cursor, Codex
- Контент: нейросети для генерации текста, изображений, видео

## Критерии качества помощника

- [ ] Роль чёткая и конкретная
- [ ] Понятно в каких ситуациях вызывать
- [ ] Есть ограничения (чего делать нельзя)
- [ ] Формат ответа прописан
- [ ] Проверен на реальном примере

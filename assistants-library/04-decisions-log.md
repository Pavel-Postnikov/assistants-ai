# Лог решений

## 2026-05-01: Структура библиотеки

**Решение:** организовать по типу задачи (что делает помощник), теги — по сфере и платформе.

**Почему:** один помощник часто подходит к нескольким сферам жизни, поэтому делить по сфере неудобно. Теги решают проблему пересечения.

**Категории на старте:** Анализ, Идеи, Текст, Планирование, Разработка, Контент, Решения.

## 2026-05-01: Индексный файл INDEX.md

**Решение:** сделать INDEX.md главным навигатором — и для человека и для LLM.

**Почему:** LLM читает INDEX первым и сразу знает в каком файле искать нужного помощника — без перебора всех файлов.

# Лог решений

## 2026-05-01: Структура библиотеки

**Решение:** организовать по типу задачи (что делает помощник), теги — по сфере и платформе.

**Почему:** один помощник часто подходит к нескольким сферам жизни, поэтому делить по сфере неудобно. Теги решают проблему пересечения.

**Категории на старте:** Анализ, Идеи, Текст, Планирование, Разработка, Контент, Решения.

---

## 2026-05-01: Индексный файл INDEX.md

**Решение:** сделать INDEX.md главным навигатором — и для человека и для LLM.

**Почему:** LLM читает INDEX первым и сразу знает в каком файле искать нужного помощника — без перебора всех файлов.

---

## 2026-05-01: Переход на подпапки и отдельные файлы

**Решение:** каждая категория — папка с `index.md` и отдельным `.md` файлом на каждого помощника. Имена файлов — латиницей через дефис.

**Почему:** один большой файл на категорию быстро становится нечитаемым при росте библиотеки. Отдельный файл = чёткая единица, легко найти, легко редактировать.

---

## 2026-05-01: Расширение тегов платформ

**Решение:** разделить платформы на три группы — чат (#чат), ИИ-агенты в IDE (#claude-code, #cursor, #codex, #copilot, #cline), контент (#контент).

**Почему:** #claude-code не покрывает Cursor и Codex — разные инструменты с разными возможностями.

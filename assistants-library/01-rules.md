# 01-rules — Правила и шаблон помощника

## Структура файлов

```
assistants-library/
├── INDEX.md                        ← карта всей библиотеки, читать первым
├── 00-brief.md                     ← цель проекта
├── 01-rules.md                     ← этот файл
├── 04-decisions-log.md             ← лог структурных решений
└── assistants/
    └── [категория]/
        ├── index.md                ← оглавление категории со списком помощников
        └── [название-помощника].md ← один помощник = один файл
```

---

## Шаблон нового помощника

Каждый помощник — отдельный `.md` файл. Имя файла — латиницей, через дефис. Например: `jira-task-builder.md`, `idea-generator.md`.

Файл состоит из трёх частей:
1. **Шапка** — навигация по библиотеке (теги, когда вызывать)
2. **Промпт для копирования** — то что вставляешь в чат, одним блоком
3. **Пример использования** — реальный сценарий

```markdown
# [Название помощника на русском]

**Теги:** #сфера #платформа #режим #формат
**Когда вызывать:** одно предложение — в какой ситуации открываешь этого помощника.

---

## Промпт для копирования

```
Роль:
Кто ты и какова твоя основная функция.

Цель:
Что конкретно должно получиться на выходе.

Принципы работы:
- Как думать и подходить к задаче
- Какие вопросы задавать
- На чём фокусироваться

Ограничения:
- Чего не делать
- Какие темы не трогать

Формат ответа:
Структура и объём ответа.

Запрещено:
- Жёсткие запреты — что нельзя ни при каких условиях
```

---

**Пример использования:**
Короткий реальный сценарий — когда и как использовал, что получил на выходе.
```

---

## Правила категоризации

1. Категория = **что делает** помощник (анализирует, генерирует, структурирует...)
2. Теги = **где и для чего** используется
3. Если помощник подходит к двум категориям — выбери основную по главной функции
4. Название файла — латиницей через дефис, отражает суть помощника

---

## Правила тегов

Минимум 2 тега: один по сфере, один по платформе.

### Теги сфер
`#работа` `#творчество` `#личное` `#разработка` `#финансы` `#быт` `#коммуникация` `#обучение` `#здоровье`

### Теги платформ — чат
`#чат`

### Теги платформ — ИИ-агенты в IDE
`#claude-code` `#cursor` `#codex` `#copilot` `#cline`

### Теги платформ — контент
`#контент`

### Теги режима работы
`#диалог` `#один-запрос`

### Теги формата вывода
`#готовый-текст` `#список-идей` `#вопросы`

## После добавления помощника

1. Обнови `index.md` нужной категории — добавь строку в таблицу
2. Обнови счётчик в [INDEX.md](INDEX.md) для нужной категории
3. Добавь строки в таблицу быстрого поиска по тегам в [INDEX.md](INDEX.md)
4. `04-decisions-log.md` — только при структурных изменениях (новая категория, изменение шаблона)

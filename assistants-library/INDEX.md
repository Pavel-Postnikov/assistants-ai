## Теги — словарь

### По сфере
- `#работа` — рабочие задачи, проекты
- `#творчество` — идеи, контент, искусство
- `#личное` — личная жизнь, саморазвитие
- `#разработка` — код, архитектура, технические решения
- `#финансы` — деньги, решения с финансовым весом
- `#быт` — повседневные задачи
- `#коммуникация` — письма, переговоры, сообщения, переписка
- `#обучение` — изучение нового, объяснения, конспекты
- `#здоровье` — спорт, питание, режим дня

### По платформе — чат
- `#чат` — любой чат-интерфейс (ChatGPT, Claude, Яндекс GPT)

### По платформе — ИИ-агенты в IDE
- `#claude-code` — Claude Code
- `#cursor` — Cursor
- `#codex` — OpenAI Codex
- `#copilot` — GitHub Copilot
- `#cline` — Cline

### По платформе — контент
- `#контент` — нейросети для генерации контента

### По режиму работы
- `#диалог` — сначала уточняет вводную, потом выдаёт результат
- `#один-запрос` — дал вводную → получил результат без лишних вопросов

### По формату вывода
- `#готовый-текст` — выдаёт документ или текст готовый к использованию
- `#список-идей` — варианты для выбора, не финальный продукт
- `#вопросы` — задаёт вопросы для размышления, не пишет за тебя
